# ASOT Training Guide — Document Template

This template is used to write training guides offline (in Google Docs or Microsoft Word) and import them into the ASOT Training Hub.

---

## How to Use This Template

1. Make a copy of this template (File > Make a copy in Google Docs).
2. Fill in every section below using the correct heading styles.
3. Export as `.docx` (File > Download > Microsoft Word in Google Docs).
4. Go to the J4 Import Panel → J3 Training → Training Guides and upload the file.
5. The guide will be created as a **draft** — review it in the editor and assign a Training Type before submitting for approval.

### Heading Styles (Important)
The importer reads the structure of this document using heading levels. Apply heading styles from the toolbar — do **not** just bold or resize text.

| Heading Level | Purpose |
|---|---|
| Heading 1 | Guide title (one only) |
| Heading 2 | Section headers — METADATA, OVERVIEW, EQUIPMENT, TEACHING POINTS, NOTES |
| Heading 3 | Teaching point name (one per teaching point) |
| Heading 4 | Sub-section within a teaching point — DOT POINTS, VITAL POINTS, COMMON FAULTS |

---

## Writing Guidelines

- **Images are not imported.** Add any images manually in the editor after import.
- **Common Faults format:** Write each fault as `fault description | correction description` on a separate bullet point. The importer splits on the `|` character.
- Leave any section empty if it does not apply — the importer will skip blank sections.
- The Training Type link is assigned manually in the editor after import.
